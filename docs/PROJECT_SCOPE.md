# Project Scope

This repository is the public, method-focused SafeSABR release.

Included:

- SafeSABR policy training.
- CVaR-style risk-calibrated PPO reward wrapper.
- Runtime safety auditor.
- StarNet-to-SABR trace conversion.
- Safe-capacity CSV exporter.
- Figures for explaining the paper background and method.

Excluded:

- StarNet raw or processed measurement data.
- Large experiment logs.
- Trained model checkpoints.
- Third-party baseline code for paper comparison.

The private backup repository keeps the full internal experiment state. This public repository is intended for readers who want to understand, reuse, or extend the SafeSABR method.
